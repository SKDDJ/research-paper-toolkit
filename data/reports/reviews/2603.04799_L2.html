S Core Contribution

The paper proposes Clustering-Sampling-Voting (CSV), a framework that reduces LLM invocations for semantic filtering from linear to sublinear complexity while providing error guarantees. CSV embeds tuples into semantic clusters, samples a small subset for LLM evaluation, and infers cluster-level labels via two voting strategies: UniVote (uniform aggregation) and SimVote (similarity-weighted voting), with re-clustering on ambiguous clusters to ensure robustness. abstract

F Mapping to Dr. Lan's 7-Layer Semantic Filter Framework

1. Data Representation Layer

Tuples from the table are embedded into a semantic space to enable clustering. The representation captures semantic similarity between tuples with respect to the natural language predicate. abstract

2. Candidate Executor / Proxy Layer

An embedding model serves as the proxy to compute semantic representations and cluster tuples, while the LLM serves as the oracle executor invoked only on sampled tuples. This creates a two-tier system where the embedding-based clustering acts as a lightweight proxy to reduce expensive LLM calls. abstract

3. Unit of Decision Layer

Rather than making decisions tuple-by-tuple (as in standard semantic filtering), CSV makes decisions at the cluster level, inferring labels for all tuples in a cluster based on sampled evaluations. This is the key insight enabling sublinear invocations. abstract

4. Predicate Transformation Layer

The natural language predicate e is used directly in prompts for sampled tuples. The transformation is implicit: the predicate's semantics are captured through the embedding space used for clustering, but the predicate itself is not decomposed or rewritten. abstract

5. Calibration / Sampling Layer

CSV samples a small subset from each semantic cluster for LLM evaluation. When clusters are ambiguous (mixed positive/negative), re-clustering is triggered to refine the groupings. This adaptive sampling strategy ensures that the sample is representative of cluster-level semantics. abstract

6. Routing / Action Layer

After sampling, labels are propagated to unsampled tuples via UniVote (uniform majority voting) or SimVote (similarity-weighted voting). The routing decision is whether to accept the cluster-level vote or trigger re-clustering for ambiguous clusters. abstract

7. Guarantee Layer

CSV provides error guarantees on the semantic filtering results, ensuring that the sublinear approximation maintains bounded error relative to full linear evaluation. The specific form of guarantees (probabilistic bounds, worst-case, etc.) is described in the full paper. abstract

M Method Components
Semantic Clustering

Tuples are embedded into a semantic space and grouped into semantic clusters based on their embeddings, enabling batch-level reasoning rather than tuple-by-tuple LLM evaluation. abstract

Sampling

A small subset of tuples is sampled from each cluster for LLM evaluation, reducing the total number of LLM invocations to sublinear in the table size. abstract

UniVote

A voting strategy that aggregates labels uniformly across sampled tuples within a cluster to infer the cluster-level label. abstract

SimVote

A voting strategy that weights votes by semantic similarity between sampled tuples and other cluster members, providing more nuanced label inference. abstract

Re-clustering

CSV triggers re-clustering on ambiguous clusters to ensure robustness across diverse datasets, handling cases where initial clustering does not cleanly separate positive and negative tuples. abstract
