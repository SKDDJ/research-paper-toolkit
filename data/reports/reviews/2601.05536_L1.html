Task Cascades for Efficient Unstructured Data Processing

S Core Contribution

The paper introduces the task cascades framework, which generalizes model cascades by varying not just the model but also the document portion and operation at each stage. An LLM agent generates simplified, decomposed, or related operations and selects relevant document portions, constructing hundreds of candidate tasks from which an effective cascade is assembled. The framework also provides an extension with statistical accuracy guarantees. abstract

M Method Components
Task Cascade Framework

Generalizes model cascades by varying the model, document portion, and operation at each stage of the cascade, rather than only the model. abstract

LLM Agent for Task Generation

Uses an LLM agent to generate simplified, decomposed, or otherwise related operations and selects the most relevant document portions, constructing hundreds of candidate tasks. abstract

Iterative Cascade Selection

An iterative approach to construct effective cascades, motivated by the intractability of optimal cascade selection (reduced from Minimum Sum Set Cover). abstract

Statistical Accuracy Guarantees Extension

An extension that ensures the resulting cascade meets a user-defined accuracy target with respect to the oracle, up to a bounded failure probability. abstract
