ThriftLLM: On Cost-Effective Selection of Large Language Models for Classification Queries

arXiv preprint 2025 Level 2 Review
Keke Huang, Yimin Shi, Dujian Ding, Yifei Li, Yang Fei, Laks Lakshmanan, Xiaokui Xiao
University of British Columbia, National University of Singapore, CNRS@CREATE, Singapore
arXiv PDF
S Core Contribution

The paper formalizes the Optimal Ensemble Selection (OES) problem of selecting a subset of LLMs under a cost budget to maximize prediction accuracy, a novel metric based on maximum-likelihood aggregation of LLM responses. It proves prediction accuracy is non-decreasing but non-submodular, designs a submodular surrogate upper bound function, and develops the ThriftLLM algorithm that achieves an instance-dependent approximation guarantee with high probability, further optimized by an adaptive selection strategy that prunes unnecessary LLM invocations at query time. Sections 2, 3, 4

F Mapping to Dr. Lan's 7-Layer Semantic Filter Framework

1. Data Representation Layer

Queries are represented as text with prompts. For success probability estimation, queries are converted to embeddings via OpenAI's embedding API and clustered using DBSCAN. Historical performance is stored in a boolean matrix T ∈ {0,1}^{N×L} recording correctness of each LLM on each query. Section 3.1

2. Candidate Executor / Proxy Layer

12 commercial LLM APIs from 5 companies (OpenAI, Google, Microsoft, Meta, Mistral AI) serve as candidate executors with varying costs ($0.055 to $15.0 per million tokens). No traditional proxy models; instead, the method selects a subset (ensemble) of these LLMs. The surrogate function γ(S) acts as a proxy for the intractable prediction accuracy ξ(S). Section 6.1, Table 4

3. Unit of Decision Layer

The ensemble selection is performed per query class (cluster of semantically similar queries). At inference time, adaptive selection operates per query, pruning unnecessary LLM invocations based on real-time observations. The budget constraint is enforced strictly per query, unlike FrugalGPT's expected-cost approach. Sections 3.1, 4.3.1

4. Predicate Transformation Layer

Rather than using a single LLM's response, ThriftLLM aggregates responses from multiple LLMs via a maximum-likelihood framework. The belief function h(C_k | ϕ_S) efficiently determines which class has the highest likelihood without computing exact likelihoods. This transforms the multi-model classification into a single aggregated prediction. Section 3.2

5. Calibration / Sampling Layer

θ Monte Carlo simulations estimate prediction accuracy ξ(·) with parameters ε=0.1, δ=0.01. Success probabilities are estimated from historical data via DBSCAN clustering of query embeddings. When probabilities have confidence intervals, a median-of-means procedure (Lemma 10) diminishes failure probability to desired levels. Sections 3.1, 4.3.2, 4.4

6. Routing / Action Layer

SurGreedyLLM selects the best ensemble among three candidates: greedy on ξ(·), greedy on surrogate γ(·), and the single best LLM. At query time, ThriftLLM's adaptive selection applies models sequentially and terminates early when the termination condition F(T*)·H_2(ϕ_S) ≤ H_1(ϕ_S) guarantees the prediction won't change, routing the query to fewer LLMs than the full ensemble. Sections 4.2, 4.3.1, Algorithms 2-3

7. Guarantee Layer

ThriftLLM provides a data-dependent approximation guarantee (Theorem 8): with probability ≥ 1-δ, the solution achieves at least (ratio - ε)(1 - 1/√e) times the optimal prediction accuracy, where the ratio depends on the gap between ξ and γ on the selected sets. Extended to confidence interval estimates (Theorem 9) with failure probability δ + L²·Σδ_l. The budget constraint is strictly enforced per query. Sections 4.2, 4.3.2, 4.4, Theorems 5, 8, 9

M Method Components
Prediction Accuracy

A novel metric prediction accuracy ξ(S) that measures the probability that the maximum-likelihood aggregated prediction from a set of LLMs S matches the ground truth on a random query from a query class. It sums over all observations where the aggregated prediction is correct, weighted by their realization probabilities. Section 2, Definition 1

Response Aggregation via Maximum Likelihood

Given an observation (set of LLM responses), the aggregated prediction is derived by computing the likelihood of each class being the ground truth and selecting the class with the highest likelihood. This is simplified using a belief function h(C_k | ϕ_S) that avoids redundant computation by factoring out shared terms. Section 3.2

Success Probability Estimation

LLM success probabilities are estimated from historical data by first converting queries to embeddings (via OpenAI embedding API), clustering them using DBSCAN, and computing per-cluster accuracy rates from a boolean performance matrix T. Section 3.1

GreedyLLM (Vanilla Greedy)

A baseline greedy algorithm that iteratively selects the LLM with the highest ratio of marginal accuracy gain to cost. Shown to have unbounded approximation factor for the non-submodular OES problem. Section 4.2, Algorithm 1

Surrogate Submodular Function γ(S)

A submodular upper bound function γ(S) = 1 - ∏_{l_k ∈ S}(1 - p_k) that upper bounds prediction accuracy ξ(S) for all subsets S. This enables leveraging known results for budgeted submodular maximization. Section 4.2, Eq. 5, Lemma 4

SurGreedyLLM (Surrogate Greedy)

Runs GreedyLLM on both the original accuracy function ξ(·) and the surrogate γ(·), also considers the single best LLM l*, and returns the solution with the highest accuracy among the three candidates. Achieves an instance-dependent approximation guarantee based on the (1 - 1/√e) factor from Khuller et al. Section 4.2, Algorithm 2, Theorem 5

ThriftLLM (Adaptive Selection)

Extends SurGreedyLLM with an adaptive pruning strategy at query time. After obtaining the ensemble S* from SurGreedyLLM, models are applied sequentially in decreasing order of success probability. A termination condition F(T*)·H_2(ϕ_S) > H_1(ϕ_S) checks whether remaining models can change the current prediction; if not, execution stops early, saving cost without changing the prediction. Section 4.3.1, Algorithm 3

Monte Carlo Estimation of ξ(·)

Since exact computation of ξ(·) is expensive (exponential in |S|), it is estimated using θ Monte Carlo simulations where θ = (8+2ε)/(ε²p*) · ln(2L²/δ), providing estimation within ε·p*/2 with probability ≥ 1 - δ/L². Section 4.3.2, Lemma 7

Extension to Probability Interval Estimates

When success probabilities are unknown and estimated with confidence intervals [p_l^⊥, p_l^⊤], ThriftLLM is run on lower, estimated, and upper probability sets. A data-dependent approximation guarantee is established with failure probability δ + L²·Σδ_l, which can be diminished via median-of-means repeated estimation. Section 4.4, Theorem 9, Lemma 10

T Theoretical Results
Lemma The prediction accuracy function ξ(·) is non-decreasing: adding models or increasing success probabilities does not decrease accuracy. Lemma 1, Section 4.1
Lemma The prediction accuracy function ξ(·) is non-submodular. Lemma 2, Section 4.1
Proposition For a set of two LLMs, ξ({l_1, l_2}) = max{p_1, p_2}. Proposition 3, Section 4.1
Proposition The prediction accuracy ξ(S) is independent of the ground-truth class C_q. Proposition 2, Section 3.2
Lemma The surrogate function γ(S) = 1 - ∏(1-p_k) is submodular and γ(S) ≥ ξ(S) for all S ⊆ L. Lemma 4, Section 4.2
Theorem SurGreedyLLM achieves an instance-dependent approximation guarantee: ξ(S*) ≥ [max{ξ(S_1), ξ(S_2), p*} / max{γ(S_2), p*}] · (1 - 1/√e) · ξ(S°). Theorem 5, Section 4.2
Theorem ThriftLLM with Monte Carlo estimation achieves: Pr[ξ(S*) ≥ (ratio - ε)(1 - 1/√e) · ξ(S°)] ≥ 1 - δ. Theorem 8, Section 4.3.2
Proposition If the adaptive termination condition F(T*)·H_2(ϕ_S) ≤ H_1(ϕ_S) holds, the prediction by subset S equals the prediction by the full set S*. Proposition 6, Section 4.3.1
Theorem With confidence interval estimates, ThriftLLM achieves a data-dependent approximation guarantee with failure probability ≤ δ + L²·Σδ_l, which can be diminished via repeated median estimation. Theorem 9, Section 4.4
Bound The OES problem is likely NP-hard, as it can be viewed as a variant of the 0-1 Knapsack problem with an exponentially harder objective function. Section 4.1 (Hardness discussion)

A Assumptions
Explicit Responses of different LLMs are mutually independent given a query. Section 3
Explicit When a model makes a wrong prediction, it predicts each of the K-1 wrong classes with equal probability (1-p_i)/(K-1). Section 2, Eq. 1
Explicit Queries from the same query class exhibit semantic similarity and share success probabilities. Section 3.1
Explicit LLMs are deterministic (temperature set to lowest), so cost b_i(q) is solely determined by query q. Section 2
Explicit Focus is restricted to classification tasks; extension to regression is left as future work. Section 2, footnote 2
L Limitations
Author-stated ThriftLLM may select weaker models on datasets with a large number of classes (e.g., Banking77 with 77 classes) due to overestimated success probabilities. Section 6.2
Author-stated The method is currently limited to classification tasks and does not handle regression or generation tasks. Section 2, Section 7
Author-stated The hardness proof for OES is informal (evidence-based argument rather than formal reduction). Section 4.1
Inferred The uniform error assumption for wrong predictions ((1-p_i)/(K-1) per wrong class) may not hold in practice. Section 2, Eq. 1
Inferred The independence assumption between LLM responses may not hold for models with similar architectures or training data. Section 3
Author-stated The approximation guarantee is instance-dependent (data-dependent ratio), not a universal constant-factor guarantee. Theorem 5, Theorem 8
